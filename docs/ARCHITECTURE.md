# Устройство сцены магазина (src/scenes)

Сцена одна — `StoreScene` (Phaser). Раньше она была одним файлом на 16 000 строк, и любые две ветки
конфликтовали в нём. Теперь в `StoreScene.ts` только состояние сцены и её каркас, а всё, что она умеет, —
в модулях по областям. Правила игры (деньги, кто придёт, что сломалось) по-прежнему в `src/game/`,
окна и панели — в `src/ui/`; `src/scenes/` — только то, как это выглядит и двигается в мире.

## Как устроен модуль

Модуль — набор функций, первый параметр у которых — сама сцена:

```ts
// src/scenes/pets.ts
export function petCat(scene: StoreScene): void {
  ...
}
```

- Состояние (поля `scene.*`) живёт на сцене, в `StoreScene.ts`, — модуль своё не заводит. Новое поле —
  в класс, рядом с похожими, с комментарием, без `private`, если оно нужно модулю.
- Сцену модуль берёт только как тип: `import type { StoreScene } from './StoreScene'`.
- Сцена и модули зовут друг друга через пространство имён: `pets.petCat(this)` из сцены,
  `effects.popup(scene, …)` из модуля; внутри своего модуля — просто `petCat(scene)`.
  Модули могут ссылаться друг на друга по кругу: при загрузке они ничего не вызывают, только объявляют функции.
- Функции без сцены (чистая геометрия, расчёт) — без параметра `scene`.
- Константы и типы одного модуля — в нём же, сверху, без `export`. Нужны двум и больше модулям — в `common.ts`.
- Шапка модуля — пара строк комментария: что здесь живёт и где соседнее.

Несколько методов остались у сцены переходниками на одну строку (`popup`, `celebrateCombo`, `updateLighting`,
`spawnCustomer`, `serveNext`, `runSonya`, `endOfDay`, `catVisit`, `refreshShelves`, `unboxables`, `packFresh`):
их вызывают или подменяют скрипты снаружи — `scripts/e2e.ts`, `scripts/ux-audit.cjs`, `scripts/promo/capture.cjs`.
`onResize` — переходник, потому что на него по ссылке подписано событие `RESIZE`. Внутри игры их зовут как
`scene.popup(…)`, чтобы подмена в промо по-прежнему срабатывала.

## Куда класть новое

- Новая вещь в зале — `building.ts` (полка — `shelves.ts`, украшение — `decorations.ts`); на улице — `streets.ts`.
- Новый гость или поведение покупателя — `shoppers.ts`; гость с улицы или из сюжета — `visitors.ts`;
  работа сотрудника — `staff.ts` (новая должность — ещё и таблица в `staff.syncStaff`).
- Новое событие дня — `liveFx.ts`, особый день — `bigDays.ts`, что-то утреннее — `morningFlow.ts`, вечернее — `nightShift.ts`.
- Большая новая область (своя механика на несколько сотен строк) — свой модуль по тем же правилам и строка в этой таблице.
- В `StoreScene.ts` — только новые поля и вызов из `create`, `update` или `buildWorld`.

Как раньше: таймеры, которые должны пережить перестройку мира, — через `worldTimer`; остановить ходьбу —
`persons.haltWalk(scene, person)`, а не `tweens.killTweensOf`; тяжёлое — с оглядкой на `scene.lite`; тряски камеры нет.
