Перетаскивай пальцем или мышью, чтобы осмотреть зал, колёсиком или двумя пальцами — приблизить. Звук, графику и язык можно поменять в настройках.

## 6. Комментарий для модератора (до 2048 знаков)

```
Игра вертикальная (портретная), на компьютере показывается по центру. Сохранения — через player.setData (облачные), с запасной копией в localStorage. Язык определяется по ysdk.environment.i18n.lang. На время рекламы и при сворачивании вкладки звук и игра ставятся на паузу.
```

## 7. Сборка для Яндекса (`npm run build:yandex`)

`npm run build:yandex` → папка `dist-yandex/` и архив **`dist-yandex.zip`** (index.html в корне, ~30 МБ,
без пробелов и кириллицы в именах) — его и загружать в поле «Архив». Сборка для Telegram (`npm run build`)
не меняется: площадка выбирается при сборке (`src/platform/target.ts`), код Яндекса в неё не попадает.

Что делает сборка для Яндекса (`src/platform/yandex.ts`):

| Требование | Как сделано |
|---|---|
| SDK (1.1, 1.19.1) | `<script src="/sdk.js">` вместо скрипта Telegram, `YaGames.init()` до запуска игры |
| Загрузка (1.19.2) | `LoadingAPI.ready()` — когда на экране кнопка «Играть» |
| Геймплей (1.19.3) | `GameplayAPI.start()` — магазин открылся, `stop()` — день закрылся, пауза, реклама |
| Язык (2.14) | `ysdk.environment.i18n.lang`; выбор игрока в настройках важнее |
| Сохранения (1.9, 1.11) | `player.setData/getData` (тот же формат, что в Telegram) + копия в localStorage; без SDK — только localStorage |
| Пауза и звук (1.3, 4.7) | `game_api_pause/resume`, реклама, скрытая вкладка — цикл игры спит, звук молчит; без фокуса — звук молчит |
| Ошибки в консоли (1.14) | запросы к нашему серверу (`/api/…`) на Яндексе не идут: календарь праздников — встроенный, отчёты об ошибках — только в консоль |

Выключено на Яндексе (живёт на нашем сервере через Telegram): друзья и улица друзей, приглашения,
«Позвать на помощь», турнир района и рейтинг, «Поддержать автора», бот. Покупки за звёзды не работают —
вместо «откройте в Telegram» игра пишет «В этой версии игры покупки недоступны».

## 8. Реклама — предложения (ждут решения автора)

Яндекс сам показывает рекламу при запуске игры. Свою — только в естественных паузах (п. 4.4), частоту
режет площадка. Код показа уже есть (`showFullscreenAd`, `showRewardedAd`), места не подключены.

**Полноэкранная (interstitial):**
1. После итогов дня, перед следующим утром — естественная пауза, игрок сам нажимает «Дальше». ← советую
2. При возвращении в игру после долгого перерыва (окно с доходом за время отсутствия).

**За награду (rewarded), только по желанию игрока, награда — бонус, не нужна для прохождения (4.5):**
1. «Удвоить подарок дня» на утреннем подарке. ← советую
2. «+50% к выручке дня» на итогах дня (меняет баланс — осторожно).
3. «Привезти заказ сразу» (срочная доставка без доплаты).

Во время рекламы игра и звук стоят — это уже сделано.
