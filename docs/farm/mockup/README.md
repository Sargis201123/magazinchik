# Лавка «Своё» — макет экрана

Один кадр второй игры (путь 2 из концепций, с теплом пути 1: лавка у дачного посёлка Сосновка).
Это картинка, а не игра: по ней решаем, как должен выглядеть экран, прежде чем писать код.

- `lavka.png` — мир 640×1300 пикселей рисунка (как экран телефона в игре, 1 пиксель рисунка = 1 пиксель холста).
- `lavka-mockup.html` — тот же кадр с панелью, табличками и репликами, как в игре.
- `compose.py` — раскладка кадра: спрайты игры из атласа + новые фермерские.
- `newart.py` — новые спрайты в стиле игры (палитра Endesga, контур `#181425`, свет сверху-слева):
  коровы, куры, грядки, пшеница, амбар, курятник, теплица, ульи, трактор, сыроварня, прилавок с весами,
  пекарня, веранда, баня, самовар, электричка.
- `atlas.py` — кадры `dist/assets/atlas0` как картинки PIL.

Пересобрать (нужна сборка `npm run build`): `python3 docs/farm/mockup/compose.py /tmp/lavka.png`.

Концепт-арт трёх путей (нейросеть по скриншоту игры, только ориентир настроения) — `docs/farm/concepts/`.
