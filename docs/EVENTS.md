# Праздники по настоящему календарю: как поменять без выпуска игры

В игре два вида праздников:

- **Праздники игрового года** (`src/game/calendar.ts`) — у каждого игрока свои: новогодняя неделя,
  8 Марта, Хэллоуин наступают по игровым дням. Их меняет только новая версия игры.
- **Праздники по настоящему календарю** (`src/game/live.ts`) — у всех в один день: 31 декабря Новый
  год и в игре, даже если в игровом году лето. Этот календарь хранится на сервере, и его можно
  поменять в любой момент — без сборки и выпуска.

Оба вида уживаются: свой праздник игрового года украшает улицу как раньше, а праздник по календарю
добавляет гирлянду на фасад, огоньки на деревья (Новый год) или тюльпаны у входа (8 Марта) — если
игровой праздник уже повесил свою гирлянду, второй не будет.

## Что даёт праздник

- **Открытка на каждый день** (адвент-календарь) — карточка сверху утреннего окна: тёплая строчка
  и немного монет. Последняя открытка — втрое щедрее. Пропустил день — не беда, считаются открытые.
- **Праздничная вещь в зал** за несколько открыток — бесплатно: ёлка (Новый год), модель парусника
  (23 Февраля), мимоза в вазе (8 Марта). Ставится у входа, её можно передвинуть или убрать в
  «Оформлении» (раздел «Праздничное»). Остаётся навсегда, даже после «Начать заново».
- **Гость** в выбранные дни: Дед Мороз или Снегурочка заходят в магазин днём и оставляют подарок.
  Раз за настоящий день, сколько игровых дней ни сыграй.
- **Набор за звёзды — по желанию**: «Новогодний набор» (снежная вывеска и зимние обои, 100 ⭐).
  Кнопка скромная, в карточке праздника прямо сказано, что всё остальное бесплатно.
- **Напоминание бота** в дни праздника — от Снегурочки, бабушки или Валентины, с портретом
  (`api/_lib/remind.ts`).

## Календарь по умолчанию

Он же встроен в игру (`DEFAULT_EVENTS` в `src/game/live.ts`) — им игра пользуется без сети или пока
вы не сохранили свой:

```json
[
  {
    "id": "newyear", "theme": "newyear", "from": "12-01", "to": "01-10",
    "cards": { "from": "12-01", "to": "12-31" },
    "guests": { "12-06": "snegurochka", "12-13": "moroz", "12-20": "snegurochka", "12-27": "moroz", "12-31": "moroz" },
    "prize": { "decor": "holiday_tree", "cards": 7 },
    "pack": "pack_newyear"
  },
  { "id": "feb23", "theme": "feb23", "from": "02-21", "to": "02-23", "cards": { "from": "02-21", "to": "02-23" }, "prize": { "decor": "holiday_ship", "cards": 2 } },
  { "id": "march8", "theme": "march8", "from": "03-06", "to": "03-08", "cards": { "from": "03-06", "to": "03-08" }, "prize": { "decor": "holiday_mimosa", "cards": 2 } }
]
```

## Поля праздника

| Поле | Что значит |
|---|---|
| `id` | Короткое имя латиницей (`a-z`, цифры, `_`). Открытые открытки привязаны к нему и к году начала — не меняйте `id` посреди праздника, иначе открытки у игроков начнутся заново. |
| `theme` | Оформление и тексты: `newyear`, `feb23` или `march8`. Новая тема (например, Хэллоуин) — только с новой версией игры: ей нужны картинки и тексты. |
| `from`, `to` | Даты праздника `ММ-ДД` по местному времени игрока, оба дня включительно. Можно через Новый год: `"12-20"` … `"01-10"`. |
| `cards` | Даты открыток `{ "from", "to" }` — внутри праздника. Строчек у Нового года 31, у 23 Февраля и 8 Марта — по 3; если дней больше, строчки идут по кругу. Нет поля — открыток нет (только украшения и гости). |
| `guests` | Дни гостей: `{ "ММ-ДД": "moroz" }` или `"snegurochka"`. |
| `prize` | Бесплатная вещь `{ "decor": "holiday_tree", "cards": 7 }` — за столько открытых открыток. Вещи: `holiday_tree`, `holiday_ship`, `holiday_mimosa`. |
| `pack` | Набор за звёзды, который предложить по желанию: `pack_newyear`. Уберите поле — кнопки не будет. |
| `decorate` | `false` — без украшений на улице. |
| `off` | `true` — праздник выключен (остаётся в списке, но не наступает). |

Праздников — до 20; если даты двух праздников пересекаются, действует тот, что выше в списке.

## Как поменять календарь

Нужны адрес игры и секрет вебхука `WEBHOOK_SECRET` (Cloudflare → Workers → magazinchik → Settings →
Variables and Secrets). Секрет никому не пересылайте и не публикуйте.

**1. Посмотреть, что сейчас действует** (видно всем, секрет не нужен):

```
https://magazinchik.sargis-zsx.workers.dev/api/events
```

`"custom": false` — действует встроенный календарь, `true` — ваш.

**2. Сохранить свой** — отправить весь список целиком (из терминала на компьютере):

```sh
curl -X POST 'https://magazinchik.sargis-zsx.workers.dev/api/events-edit' \
  -H 'x-key: <WEBHOOK_SECRET>' -H 'content-type: application/json' \
  -d '{ "events": [ … весь список, как в примере выше … ] }'
```

Секрет — в заголовке `x-key`, а не в адресе: адреса запросов Cloudflare пишет в журналы, заголовки — нет.
Длинный список удобнее держать в файле `events.json` (`{ "events": [ … ] }`) и отправлять так:
`-d @events.json`.

Сервер сначала всё проверяет: если где-то ошибка (неверная дата, неизвестный гость или вещь), он
ничего не меняет и отвечает списком ошибок по-русски — например,
`events[0]: from и to — даты «ММ-ДД»`. Всё верно — ответ `{"ok": true, …}`.

**3. Вернуть встроенный:**

```sh
curl -X POST 'https://magazinchik.sargis-zsx.workers.dev/api/events-edit' \
  -H 'x-key: <WEBHOOK_SECRET>' -H 'content-type: application/json' -d '{ "reset": true }'
```

Без терминала — через панель Cloudflare: Storage & Databases → D1 → `magazinchik` → Console:

```sql
INSERT OR REPLACE INTO settings (key, value, updated) VALUES ('events', '[ … весь список … ]', 0);
-- вернуть встроенный:
DELETE FROM settings WHERE key = 'events';
```

Здесь проверки нет: если в JSON ошибка, сервер молча вернётся к встроенному календарю (и запишет
ошибку в лог) — после правки откройте `/api/events` и убедитесь, что там ваш список.

## Когда изменения дойдут до игроков

- Сервер держит календарь в памяти до минуты.
- Игра спрашивает календарь при запуске и помнит его 3 часа (и без сети празднует по последней
  копии). Значит, новые даты у всех — в течение нескольких часов; кто запустит игру впервые — сразу.
- Бот берёт календарь при каждой рассылке напоминаний.

## Примеры

**Сдвинуть Новый год на 15 декабря** — поменять `from` и `cards.from` на `"12-15"`.

**Добавить гостя 24 декабря** — в `guests` добавить `"12-24": "snegurochka"`.

**Ёлка за 5 открыток вместо 7** — `"prize": { "decor": "holiday_tree", "cards": 5 }`.

**Выключить 23 Февраля** — добавить этому празднику `"off": true`.

| Картинки: открытки, гости, вещи, набор | `art/holidays.py` → `python3 art/holidays.py` |
| Напоминания бота | `api/_lib/remind.ts` |
