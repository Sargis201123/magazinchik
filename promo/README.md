# Промо-ролик «Магазинчика» с голосом

Вертикальный ролик 1080×1920 (Telegram, TikTok, Reels, Shorts), ~50 секунд: бабушка оставляет ларёк →
первые покупатели и тап по кассе → магазин растёт (кассиры, пекарня, кофейня, кухня) → кот, зима и
огни, улица друзей → письмо бабушки с тетрадью и вырванной страницей → мост в Заречье → «Найди
«Магазинчик» в Telegram». Всё снято в самой игре, покадрово (плавно, без тряски камеры).

## Что где

| Файл | Что это |
|---|---|
| `lines.json` | **Весь текст ролика**: реплики, подписи сцен, название, призыв и ссылка на бота (`link`) |
| `script.md` | Сценарий: что в кадре под каждой репликой |
| `voice/script_for_elevenlabs.txt` | Текст для ElevenLabs — вставить целиком, или по репликам |
| `voice/lines/01.txt … 11.txt` | По одной реплике в файле |
| `footage/*.mp4` | Снятые клипы сцен (без звука), по одному на реплику |
| `out/magazinchik_promo_ru_preview.mp4` | Превью: без голоса, тайминг по оценке — посмотреть монтаж |
| `out/magazinchik_promo_ru.mp4` | Готовый ролик с голосом (появится после сборки с голосом) |
| `out/*_square.mp4` | Квадрат 1080×1080 (лента VK/Instagram) |
| `out/magazinchik_promo_ru.srt` | Субтитры отдельным файлом (по голосу) |
| `out/magazinchik_promo_ru_poster.png` | Обложка 1080×1920 (кадр концовки) |
| `record.ts`, `build.py`, `build.sh` | Съёмка и сборка — перезапускаются после обновлений игры |

## Как сделать финальный ролик (3 шага)

1. **ElevenLabs** → Text to Speech, голос **Alexandr Vlasov – Vibrant and Energetic**, модель
   **Eleven v4**, русский. Откройте `promo/voice/script_for_elevenlabs.txt`:
   - **проще всего** — скопируйте блок «ВСТАВИТЬ ЦЕЛИКОМ» (между линиями) и сгенерируйте одним файлом;
   - или сгенерируйте каждую реплику отдельно (тексты в `promo/voice/lines/`).
2. **Положите звук** в папку `promo/voice/`:
   - один файл → `promo/voice/voice.mp3`;
   - или по репликам → `promo/voice/01.mp3`, `02.mp3`, … `11.mp3` (номера как в тексте).
   Годятся mp3, wav, m4a, ogg. Если лежат оба варианта — берётся `voice.mp3`.
3. **Соберите** (из корня репозитория):

   ```bash
   bash promo/build.sh
   ```

   Готово: `promo/out/magazinchik_promo_ru.mp4` (+ квадрат, .srt, обложка). Сборка сама меряет
   длительность каждой реплики, подгоняет под неё длину клипов и время субтитров. Один общий файл
   режется на реплики по паузам «...» — если скажет, что пауз не хватает, сгенерируйте по репликам.

Нужны только `python3` и `ffmpeg` (на Mac: `brew install ffmpeg`). Сборка идёт 3–6 минут.

## Поменять текст или ссылку на бота

- Ссылка на бота — одно место: `"link"` в `promo/lines.json` (например `"@magazinchik_bot"`).
  Пусто — в концовке только «Найди «Магазинчик» в Telegram». После правки — `bash promo/build.sh`.
- Текст реплик — `"voice"` в `lines.json` (субтитры берутся оттуда же; `"sub"` — если в субтитрах
  нужно написать иначе, чем говорит голос). Потом озвучить заново и собрать.

## Переснять кадры после обновления игры

```bash
npm ci
NODE_PATH=$(npm root -g) bash promo/build.sh --record
```

Нужны Playwright с Chromium (`npx playwright install chromium`) и ffmpeg. Съёмка идёт ~30–40 минут
(браузер рисует без видеокарты; ролик всё равно плавный — игра шагает ровно по 1/30 секунды на кадр).
Одну сцену: `npx vite-node promo/record.ts -- --only cat` (при запущенном `npx vite preview --port 4173`).
Посмотреть, что попадёт в кадр, не снимая клипы: `--explore` (по 3 кадра в `promo/.explore/`).

## Звук

Голос — сверху. Под ним — главная тема игры (Suno, `public/audio/music/suno/theme`) и шум улицы,
они плавно приглушаются, пока звучит голос. Тихие акценты из звуков игры: дверь, звон монет на
тапах, «динь», мяу, шелест страницы, колокольчик в конце. Громкость сведена к −14 LUFS (норма
TikTok/Reels/YouTube), в начале и конце — плавное появление и затухание.
